    OpenSSL¶

    The tests exchange messages with the openssl command found on the PATH. They skip when it is missing, so run make test TESTFLAGS=-v to see whether they ran. They pass with OpenSSL 3.0 and 4.1. This page lists only what those tests check.

    Certificate bundle from DegenerateCertificate and CRL message from DegenerateCRL openssl pkcs7 -inform DER -in bundle.p7b TestDegenerateCertificate, TestDegenerateCRL

    OpenSSL accepts every message. Where a message carries content, the tests compare what OpenSSL returns with the original.

    TestDecrypt also decrypts four EnvelopedData messages that OpenSSL produced when the tests were written. They are stored in decrypt_test.go with the commands that made them:

    Command Content cipher Key transport
    openssl cms -encrypt -in test.txt cert.pem DES-EDE3-CBC PKCS #1 v1.5
    openssl smime -encrypt -in test.txt -aes256 -outform pem certificate.pem AES-256-CBC PKCS #1 v1.5
    openssl cms -encrypt ... -aes256 -keyopt rsa_padding_mode:oaep AES-256-CBC RSAES-OAEP with SHA-1
    The same with -keyopt rsa_oaep_md:sha256 AES-256-CBC RSAES-OAEP with SHA-256

    Line endings¶

    OpenSSL treats the input as text unless -binary is given and converts line endings to CRLF before signing. The signed content then differs from the file on disk, so a detached signature made that way verifies only against the converted bytes. The tests pass -binary when they sign with openssl cms.

    What OpenSSL can produce but this library cannot read¶

    OpenSSL also writes structures outside the Support matrix, such as recipients identified by subject key identifier (-keyid), AES-GCM content in AuthEnvelopedData and recipients with EC keys. Known limitations lists them.
